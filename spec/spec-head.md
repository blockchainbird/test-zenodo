## Intro

This is a Spec-Up-T installation used to test automating Zenodo DOI **updates**
(new versions) via GitHub Actions. The initial DOI creation remains manual.

See the Spec-Up-T guide:
[Create a Zenodo DOI](https://trustoverip.github.io/spec-up-t-website/docs/developer-documentation/create-zenodo-doi).
